Pull to Refresh with CSS

Pull down at the top to refresh. The gesture is processed 100% natively by the browser compositor with zero touchmove or mousemove listeners.

⚡ How It Works via CSS Functions

  • • CSS Scroll Snap: scroll-snap-type: y mandatory handles resting boundaries between the PTR header and content.
  • • CSS view() Function: animation-timeline: view() rotates and scales the spinner directly on the GPU as the header enters the viewport.
  • • Zero Touchmove Listeners: Gesture tracking, rubber-banding, and physics are handled entirely off-main-thread by Chromium’s compositor.
  • • Native scrollend Event: JavaScript only triggers the data refresh when the user finishes pulling and the viewport rests at the top snap point.
